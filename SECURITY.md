# Security Policy

## Public demonstration scope

SpaceBNS is currently an educational proof of concept using synthetic data. It
must not be connected to flight hardware, operational mission networks, or
sensitive customer environments.

## Never publish

- credentials, API keys, tokens, certificates, or private keys;
- real spacecraft telemetry or command history without explicit authorization;
- customer, partner, or employee data;
- export-controlled or mission-sensitive technical information;
- proprietary BNS Innovation model weights or training data; or
- real aerospace network topology and security configuration.

## Reporting a vulnerability

Do not disclose exploitable details in a public issue. Contact the repository
owner privately through GitHub's security-reporting mechanism when enabled.

## Operational disclaimer

No code in this repository is approved for safety-critical, mission-critical,
or flight use. Any future deployment requires an independent threat model,
requirements traceability, verification and validation, and mission authority.
